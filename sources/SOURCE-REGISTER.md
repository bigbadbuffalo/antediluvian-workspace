# Primary and Secondary Source Register

**State:** Intake candidates, not verified bibliography and not setting canon. Every source added below needs an edition/witness check before supporting factual claims.

Use [SOURCE-ENTRY-TEMPLATE.md](SOURCE-ENTRY-TEMPLATE.md) for each verified record, with stable source IDs (SRC-001, SRC-002...). Full text is not required: citation, edition, license and precise references matter more.

## Registration rules

- Assign stable SRC identifiers once researched.
- Record title, component/recension, approximate composition range, earliest witness, language, translator/editor, publication, stable URL, and limits of access.
- Link research claims using SRC IDs and passage/fragment IDs.
- Mark confidence in the *attribution/attestation*, not confidence that supernatural narratives historically occurred.
- Register scholarly criticism and dissent; do not manufacture “consensus.”
- Record copyrighted books as bibliographic references, not full scans/transcriptions.
