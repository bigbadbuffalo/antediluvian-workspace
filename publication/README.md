# Publication — Reserved for Future Use

**No player wiki is active, configured or requested.** This directory records future requirements only.

When the author elects to publish:
- Export approved canon from the canonical authoring tree, never from research/workshop/sources by default.
- Use explicit status + visibility metadata, with missing or invalid values **excluded** by default.
- Separate player-safe articles from substantial GM spoilers; test filtered output against a denylist.
- Audit generated navigation, links, media licensing, hidden page counts and leak risks.
- Keep web publication downstream from the repository; do not let website edits secretly redefine canon.
- Prefer intentional deployment over publishing every unreviewed draft until an alternative cadence is chosen.

**Security:** This GitHub repository is public now. Visibility metadata only controls a *future exporter*; it cannot shield GitHub source files or history. Revisit repository privacy before storing spoilers. Do not turn on a GitHub Pages workflow merely because this directory exists.
