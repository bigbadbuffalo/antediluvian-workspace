**No setting encyclopedia articles have been canonized yet.** This area is reserved for explicitly approved, internally coherent lore.

Potential categories (create only as material warrants): history/chronology, cosmology/theology, geography, civilizations/peoples, institutions/religion, supernatural beings, technology/material culture, ecology/creatures, notable figures, and adventures/campaign framing.

Use [ARTICLE-TEMPLATE.md](ARTICLE-TEMPLATE.md). A topic should have one authoritative home, with links or brief summaries elsewhere. Different in-world accounts can coexist if the article distinguishes belief from objective setting truth.

Canonical fact requires an approved DECISION; external texts never automatically create canon. This folder's existence does not make draft text canon.
